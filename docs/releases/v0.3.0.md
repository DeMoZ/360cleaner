Первый релиз с установщиком: программа на Rust для Mac (Apple Silicon) и Windows.

## Что нового

- Исправлено: окно не получало ответы от обработки — после загрузки фото ничего не происходило.
- Сохранение в полном разрешении стало быстрым и совпадает с превью; качество JPEG 95 вместо 75.
- Метаданные 360° (XMP GPano, EXIF, ICC) переносятся в результат правильно.
- Точки шума больше не раздуваются в большие пятна; зоны находятся устойчивее, в том числе на шве панорамы.
- Ползунки не запускают лишние расчёты, параметры запоминаются.
- 360° просмотр плавнее; клавиши 1–4, S, пробел, ⌘S, ⌘O, ⌘Q.
- Предупреждения: кадр не 2:1, фото разного размера, кадры не различаются.
- Поддержка TIFF.
- Обновление из программы (кнопка с версией вверху, автоматическая проверка раз в сутки) и окно «Поддержать».

## Установка

- Mac: `360Cleaner-macOS-v0.3.0.dmg`, перетащите приложение в «Программы». Приложение не подписано: при первом
  запуске откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- Windows: распакуйте `360Cleaner-0.3.0-windows-x64.zip` и запустите `360Cleaner.exe` (SmartScreen: «Подробнее» →
  «Выполнить в любом случае»).
