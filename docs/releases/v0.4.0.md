## What's new

- The interface is now in 8 languages: English, Русский, Español, Português, Deutsch, Français, 中文, 日本語.
  The app opens in your system language (or English if it isn't one of them); you can switch it at the bottom of
  the sidebar.
- File dialogs and the donate window follow the chosen language too.

## Что нового

- Интерфейс на 8 языках: English, Русский, Español, Português, Deutsch, Français, 中文, 日本語. Программа
  открывается на языке системы (или на английском, если его нет в списке); сменить язык можно внизу боковой панели.
- Диалоги выбора файлов и окно «Поддержать» тоже на выбранном языке.

## Installation

- Mac: download `360Cleaner-macOS-v0.4.0.dmg` and drag the app to Applications. The `…-macos-arm64.zip` file is
  for in-app updates. The app isn't signed with an Apple certificate, so macOS blocks the first launch: click
  **Done**, open **System Settings → Privacy & Security** and click **Open Anyway**.
- Windows: unzip `360Cleaner-0.4.0-windows-x64.zip` and run `360Cleaner.exe` (SmartScreen: **More info** →
  **Run anyway**).

## Установка

- Mac: `360Cleaner-macOS-v0.4.0.dmg`, перетащите приложение в «Программы». Файл `…-macos-arm64.zip` — для
  обновления из программы. Приложение не подписано сертификатом Apple: при первом запуске нажмите «Готово»,
  откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- Windows: распакуйте `360Cleaner-0.4.0-windows-x64.zip` и запустите `360Cleaner.exe`.
