## What's new

- The approximate **file size** is shown next to the JPEG quality and changes at once while you move the slider,
  for the chosen size. It's measured with the same encoder that saves the file, usually within a few percent.

## Что нового

- Рядом с качеством JPEG виден примерный **вес файла**: он меняется сразу, пока двигается ползунок, для
  выбранного размера. Считается тем же кодировщиком, что сохраняет файл, ошибка обычно в несколько процентов.

## Installation

- Mac: download `360Cleaner-macOS-v0.5.1.dmg` and drag the app to Applications. The `…-macos-arm64.zip` file is
  for in-app updates. The app isn't signed with an Apple certificate, so macOS blocks the first launch: click
  **Done**, open **System Settings → Privacy & Security** and click **Open Anyway**.
- Windows: unzip `360Cleaner-0.5.1-windows-x64.zip` and run `360Cleaner.exe` (SmartScreen: **More info** →
  **Run anyway**).

## Установка

- Mac: `360Cleaner-macOS-v0.5.1.dmg`, перетащите приложение в «Программы». Файл `…-macos-arm64.zip` — для
  обновления из программы. Приложение не подписано сертификатом Apple: при первом запуске нажмите «Готово»,
  откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- Windows: распакуйте `360Cleaner-0.5.1-windows-x64.zip` и запустите `360Cleaner.exe`.
