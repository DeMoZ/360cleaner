## What's new

- **Cubemap export.** Next to the size there's a new **Format** choice: the 360° panorama as before, or a cubemap
  of six square 90° faces for game engines and 3D viewers (Unity, three.js, krpano, Pannellum). It can be saved as
  **6 files** (`name_f/_r/_b/_l/_u/_d.jpg`), a **6×1 strip** in Unity's order, or a **4×3 cross**. The face side
  is a quarter of the panorama width (8K gives 2048×2048 faces). The approximate file size is shown for the
  cubemap too.

## Что нового

- **Сохранение в кубическую карту.** Рядом с размером появился выбор **«Формат»**: панорама 360°, как раньше, или
  кубическая карта (cubemap) — шесть квадратных граней по 90° для игровых движков и 3D-просмотрщиков (Unity,
  three.js, krpano, Pannellum). Её можно сохранить **шестью файлами** (`имя_f/_r/_b/_l/_u/_d.jpg`), **полосой
  6×1** в порядке Unity или **крестом 4×3**. Сторона грани — четверть ширины панорамы (из 8K — грани 2048×2048).
  Примерный вес файла виден и для кубической карты.

## Installation

- Mac: download `360Cleaner-macOS-v0.6.0.dmg` and drag the app to Applications. The `…-macos-arm64.zip` file is
  for in-app updates. The app isn't signed with an Apple certificate, so macOS blocks the first launch: click
  **Done**, open **System Settings → Privacy & Security** and click **Open Anyway**.
- Windows: unzip `360Cleaner-0.6.0-windows-x64.zip` and run `360Cleaner.exe` (SmartScreen: **More info** →
  **Run anyway**).

## Установка

- Mac: `360Cleaner-macOS-v0.6.0.dmg`, перетащите приложение в «Программы». Файл `…-macos-arm64.zip` — для
  обновления из программы. Приложение не подписано сертификатом Apple: при первом запуске нажмите «Готово»,
  откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- Windows: распакуйте `360Cleaner-0.6.0-windows-x64.zip` и запустите `360Cleaner.exe` (SmartScreen: «Подробнее» →
  «Выполнить в любом случае»).
